HOW TO USE
================================================================================

QUICK START:
  cd frontend
  npm install
  npm start
  # Open http://localhost:3000

TESTING YOGA:
  1. Click "Start Pose"
  2. Select a yoga pose from dropdown
  3. Read instructions on screen
  4. Replicate the pose in front of camera
  5. When skeleton turns green, you're doing it correctly!
  6. Adjust confidence threshold if needed (80-100% slider)
  7. Session automatically saved to IndexedDB

VIEWING HISTORY:
  ✅ History component shows in UI
  ✅ Displays statistics (total sessions, average duration, best time)
  ✅ Lists recent sessions with dates and confidence settings
  ✅ Data persists across browser sessions
